# Support

Start with the [usage guide](docs/USAGE.md). It covers supported files,
administrator prompts, disk images, and settings.

For a bug report, include:

- Unquarantine version and macOS version
- The file type involved (`.app`, `.dmg`, or `.iso`)
- What you expected and what happened
- Steps that reproduce the issue

Do not attach an app or disk image unless it is safe to share. Remove personal
paths and other private details from screenshots or logs. For a security
concern, use the private reporting process in [SECURITY.md](SECURITY.md).
