# Changelog

Changes worth calling out are recorded here. Versions follow the version shown
in the app.

## 0.1.0

- Initial version of Unquarantine.
- Prepare `.app`, `.dmg`, and `.iso` files with an explicit trust step.
- Add optional `/Applications` monitoring and appearance preferences.
- Include a native SwiftUI interface for macOS 26 and later, built for Apple
  silicon and Intel.
