# Security

Please report security concerns privately through GitHub’s **Report a
vulnerability** feature on the repository’s Security tab. Do not post unfixed
vulnerabilities in a public issue.

Include the affected version, macOS version, impact, and a concise way to
reproduce the issue. There is no fixed response-time commitment; reports are
reviewed by the project maintainer.

Unquarantine is a narrow exception tool. It removes the quarantine attribute
from the app you approve; it does not verify the app, scan it for malware, or
change Gatekeeper’s system-wide setting. Review the source of an app before
continuing.
